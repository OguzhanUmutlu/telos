# Voxel Original Assets

This directory contains original engine and game assets released under the project's license.

- **Namespace:** `voxel` (e.g. `voxel:stone`, `voxel:textures/block/stone.png`)
- **Format:** Native RON/JSON definitions, textures, and models.

## Development Placeholders
During development, placeholder assets from Classic Voxel 26.2 live in `dev-assets/classic-26.2/`
(git-ignored per ADR-22). They must **never** be committed to the repository or packaged into
redistributable builds.
